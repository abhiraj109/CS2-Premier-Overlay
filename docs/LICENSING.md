# Project license

Abhiraj Ahire approved the [MIT License](../LICENSE) for the project's own code and documentation. MIT gives users permission to reuse and distribute changes while keeping the copyright and license notice. The [third-party notices](THIRD_PARTY.md) cover the attribution artwork and provider terms.

| License | Practical effect |
| --- | --- |
| [MIT](https://opensource.org/license/mit) | Permissive. Modified and proprietary distributions may reuse the code with the copyright and license notice. |
| [Apache-2.0](https://opensource.org/license/apache-2-0) | Permissive with an express patent grant and patent termination terms. Distributors keep the required notices and identify changed files. |
| [GPL-3.0](https://opensource.org/license/gpl-3-0) | Strong copyleft. Distributing covered modified or derivative programs generally requires corresponding source and GPL-compatible distribution terms. |
