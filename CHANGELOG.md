# Changelog

## 4.1.0 — first public release

- Packaged the existing 640 × 180 overlay, automatic Steam detection, GSI, Leetify profile sync, local match history and Settings for Windows.
- Added an offline launch option, labeled sample data, Windows documentation, GitHub checks and a reproducible release ZIP.
- Moved settings and SQLite to the user's Local AppData directory. See the [migration steps](docs/INSTALLATION.md#update-migrate-or-uninstall) for earlier builds.
- Preserved verified history across malformed provider responses and kept API keys off redirected requests.
