# Code of conduct

Treat contributors and users with respect. Discuss behavior and code with concrete examples, offer constructive feedback, and give people room to learn. Harassment, threats, discriminatory remarks, sexualized conduct, doxxing and sharing another person's private data without consent are unacceptable.

This applies to the project repository, issues, pull requests, discussions and official project spaces. For confidential reports, send a private message to the project maintainer through the contact provided on the maintainer's GitHub profile. GitHub's abuse reporting is available for conduct that violates its rules. Include links or references and describe the impact without reposting sensitive information.

Maintainers handle reports discreetly and may remove content, restrict participation or ban people based on severity and recurrence. Affected contributors can ask the maintainer to review a decision privately.
